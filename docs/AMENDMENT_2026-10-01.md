# Analysis amendment, 2026-10-01 (publication round 3)

The unchanged `PREREGISTRATION.md` and SHA sidecar are an **analysis specification**, not proven preregistration. The initial Git commit contains specification and results together; no earlier independent timestamp receipt is available. Its original pre-results/completion assertions do not establish chronology.

This dated amendment permits diagnostic integration output after a failed match gate. It does not authorize operational recommendations. It narrows the question to whether public CSV inputs can be ingested, screened, traced and rendered consistently. No outperform, surplus accuracy, Canadian replication or methodological novelty claim remains.

Deviations from the frozen specification:

- Seattle mileage is synthetic: NYC class medians plus seeded Gaussian noise (15% SD, 500 km floor), not measured evaluation data. Laval is ingestion only; no proxy baseline, scenarios or replication are performed.
- Composite terms are normalized within equipment class using reversed min-max mileage, age and annual emissions mass, rather than quartile utilization and g/km intensity. Weights remain 0.4/0.3/0.3. Mileage is `(class_max_km - km) / (class_max_km - class_min_km)`; age uses fixed analysis year 2026 minus model year, then forward min-max scaling; annual CO2 kg uses forward min-max scaling. Each constant group contributes zero. See the technical report for all three formulas.
- NYC quartile-versus-median overlap includes flagged and unflagged groups. It is descriptive label overlap, not precision or independent ground truth. Rank diagnostics compare NYC composite to g/km alone, rather than the frozen annual-mass target. They share factors and have no holdout evaluation.
- B2 is a kilometre-only light-duty proxy. Toronto also uses engine hours and usage frequency: [2026 Fleet Services report](https://www.toronto.ca/legdocs/mmis/2026/gg/bgrd/backgroundfile-284575.pdf). These missing service inputs preclude surplus recommendations.
- Light-duty inventory scope now requires a known light weight class and rejects identified duty tokens; specialization remains unresolved. SERVICE BODY and CUTAWAY can pass this token screen. Source weight/body/descriptions are retained. Catalogue text/fuel matches do not resolve engine/transmission variants. Fuel-compatible means, observed extrema, class proxies and unsupported factors are separated.
- The 50% catalogue-match gate failed in the reviewed run. Current status is generated in Results; output continues solely to expose diagnostics and missing evidence. A narrow conditional row-bootstrap can pass its width gate without resolving model uncertainty. No gate passing implies validation.
- The row-bootstrap interval targets iid empirical simulated record draws, not actual finite-fleet emissions. The added assumption envelope uses chosen mileage multipliers 0.7/1.3 and observed factor extrema, with no coverage guarantee or calibration sampling model.
- No compatible payload/body/seating/mission/availability evidence exists for catalogue options. Feasibility, fleet savings and operational plans are withheld. Promised scenario confidence intervals are not implemented; none are claimed.
- Previously undocumented constants CAD 35,000 ICE / 45,000 BEV base capital, FX 1.35, and 70% tailpipe reduction were implementation additions. FX and historical in-service capital are no longer used in catalogue illustrations. New fictional comparable base-vehicle examples use CAD 35,000 ICE, CAD 45,000 BEV, CAD 3,500 charger per unit; 10 years, 5% real discount, no upfits/tax/residuals. Each of two fictional vehicles travels 12,000 km; gasoline uses 960 L, diesel 1,080 L, BEV 20 kWh/100 km. Default prices and maintenance follow the frozen table. Six economic ranges now vary this fictional NPV, not physical emissions or municipal savings.
- Full mileage/service transfer gives 100% BEV vehicle tailpipe CO2 reduction. Upstream electricity and manufacturing are excluded. The old unexplained 70% assumption is removed.
- Federal checking now parses fiscal labels and separates scope-1 on-road gasoline/diesel CO2e/L. Illustrative reference CO2 factors are 2.3/2.7 kg/L, not a certification threshold. Scope differences, blends, rounded source emissions and exclusions are reported.
- Stage memory is process high-water RSS. OS/architecture is not hardware specification. Timing through CSV/HTML omits imports, startup and final JSON/Markdown metadata serialization. Current input observations, dependency pins and local verification receipts replace unsupported historical benchmarks.

Measured utilization, fuel/engine/transmission, payload and seating, duty/dispatch requirements, upfit specifications, replacement quotes and availability are required before extending this demonstration to fleet decisions. Independent labels and held-out evaluation would be required for any comparative performance claim.
